# 🚀 Venstogram — Социальная сеть и стриминг-платформа (Telegram Mini App + Bot)

Полнофункциональная платформа следующего поколения, объединяющая возможности **Instagram**, **TikTok**, **TikTok Live PK Battles**, **Telegram Marketplace** и **P2P мессенджера** внутри экосистемы Telegram.

---

## 🌟 Ключевой функционал

### 1. Архитектура и интеграция с Telegram
* **Telegram Bot (Aiogram 3.x)**:
  * Обработка `/start`, реферальных ссылок (`t.me/venstogrambot?startapp=...`).
  * Диплинки на конкретные посты, баттлы и профили.
  * Прямая публикация контента из ЛС: отправьте боту фото или видео с подписью — пост сразу появится в вашей ленте Venstogram!
  * Сервисные push-уведомления (вызов на баттл, звонки, личные сообщения).
* **Telegram Mini App (TMA)**:
  * Полноэкранное веб-приложение на React с интеграцией `Telegram WebApp SDK`.
  * `expand()`, тактильный отклик `HapticFeedback` при лайках и донатах, системная кнопка «Назад», адаптация под темную тему Telegram.
* **Мультиязычность (i18n)**:
  * Автоопределение языка из `initDataUnsafe.user.language_code` и ручной переключатель на 4 языка:
    1. 🇷🇺 Русский
    2. 🇺🇿 O'zbekcha (lotin)
    3. 🇺🇿 Ўзбекча (кирилл)
    4. 🇬🇧 English
* **Оффлайн-устойчивость & Data Saver**:
  * Клиентское кэширование ленты и stories для чтения без интернета.
  * Режим экономии трафика Data Saver со сжатием фото/видео.
* **Звук и тактильный отклик**:
  * Синтезатор Web Audio API: звуки лайков, фанатских донатов, рева спорткара, фанфар короны и входящего телефонного звонка.

### 2. Аутентификация и безопасность
* **Бесшовная авторизация**: Валидация криптографической подписи `initData` по алгоритму HMAC-SHA256 (пароли не требуются, жесткая привязка к Telegram ID).
* **Экран защиты кошелька**: Биометрия через `Telegram BiometricManager` (Face ID / Touch ID) или 4-значный PIN-код.
* **База данных**: SQLAlchemy 2.0 Async (SQLite по умолчанию, полная совместимость с PostgreSQL / Supabase).

### 3. Лента, публикации и Stories
* **Лента постов**: Фото, видео, карусели, счетчики лайков, просмотров и комментариев. Двойной тап для лайка с вылетом сердца.
* **Stories**: Верхняя карусель с градиентной подсветкой непросмотренных историй, полноэкранный просмотр с таймлайном, паузой по удержанию и быстрыми реакциями (❤️, 🔥, 👏, 😂).
* **Комментарии**: Всплывающая шторка комментариев под каждым постом.

### 4. Короткие вертикальные видео (Reels)
* Вертикальный полноэкранный плеер с плавным свайпом вверх/вниз и автовоспроизведением.
* Включение/выключение звука, кнопка поделиться через нативный `Telegram.WebApp.switchInlineQuery`.

### 5. Прямые эфиры и Live PK Баттлы
* **Стриминг 1-на-1**: Разделенный экран (Хост vs Соперник).
* **Механика баттла**: Таймер, штрафное задание для проигравшего (напр. *«30 приседаний в прямом эфире»*).
* **Динамическая шкала очков**: Синяя и красная шкалы в реальном времени.
* **Топ спонсоров (MVP)**: Топ-3 донатера баттла.
* **Анимированные подарки**:
  * 🌹 Роза (5 🪙)
  * ❤️ Сердце (20 🪙)
  * 🔥 Огонь (50 🪙)
  * 🏎️ Спорткар (200 🪙)
  * ✈️ Бизнес-джет (500 🪙)
  * 🦁 Королевский Лев (1000 🪙)
  * 👑 Императорская Корона (2500 🪙)
* **Монетизация**: Автоматический сплит — 40% стримеру, 60% платформе.

### 6. Личные сообщения и WebRTC звонки
* Realtime мессенджер со статусами «В сети», чекбоксами прочтения и историей сообщений.
* 1-на-1 Аудио и Видеозвонки со звуком рингтона и управлением микрофоном/камерой.

### 7. Маркетплейс юзернеймов и верификация
* **Биржа юзернеймов (@username)**: Аукцион коротких и премиум ников со ставками и моментальным выкупом (`Buyout`).
* **Подписка Venstogram Verified**: Синяя галочка на 1, 3 или 12 месяцев, дающая **3-кратный буст** показов в ленте и рекомендациях.

### 8. Внутренний кошелек (Wallet) и платежи
* Баланс в **Vensto Coins** и эквивалент в **UZS (сум)** (курс 1 монета = 100 UZS).
* Пополнение через Click, Payme, Uzum и Telegram Stars.
* Заявки на вывод средств на карты Uzcard / Humo.

### 9. AI-модерация и Многоуровневая Admin Panel
* **AI-сканер**: Автоматический анализ текстов и медиа (NSFW, запрещенные фразы) с расчетом рейтинга угрозы.
* **Админка по ролям**:
  * 💼 **Директор**: Финансовые показатели, обороты баттлов, чистая прибыль платформы (60%), аудит-лог.
  * ⚖️ **Модератор**: Очередь жалоб, дашборд AI-угроз, блокировка пользователей и контента.
  * ⚙️ **Главный по IT**: Состояние БД, пломбы целостности, активные узлы WebSocket.
  * 💻 **Разработчик**: Системные метрики (CPU/RAM), логи платформы.

## 🛠️ Запуск проекта

### 1. Запуск в один клик (Windows):
* Дважды нажмите на файл [ЗАПУСТИТЬ_БОТА.bat](file:///d:/VENSTOGRAMBOT/ЗАПУСТИТЬ_БОТА.bat) в папке проекта.
* Или используйте [ЗАПУСТИТЬ_С_ТУННЕЛЕМ_CLOUDFLARE.bat](file:///d:/VENSTOGRAMBOT/ЗАПУСТИТЬ_С_ТУННЕЛЕМ_CLOUDFLARE.bat) для одновременного запуска публичного HTTPS-туннеля для Telegram Mini App.

### 2. Запуск через консоль:
```bash
python run.py
```

После старта будут доступны:
* **Telegram Mini App**: [http://localhost:8000/app](http://localhost:8000/app)
* **Swagger API Docs**: [http://localhost:8000/docs](http://localhost:8000/docs)
* **Telegram Bot**: [@venstogrambot](https://t.me/venstogrambot)

## 📱 Привязка к Telegram Bot (BotFather)
Чтобы открыть Mini App прямо внутри Telegram:
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Введите команду `/mybots` и выберите `@venstogrambot`.
3. Перейдите в **Bot Settings** -> **Menu Button** -> **Configure menu button**.
4. Укажите URL вашего сервера (например через ngrok / cloudflare: `https://your-domain.ngrok-free.app/app`).
5. Нажмите кнопку меню в боте — и Venstogram откроется прямо внутри Telegram!
